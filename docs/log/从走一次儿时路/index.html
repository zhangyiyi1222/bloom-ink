从走一次儿时路

张中伟 / 2014年2月14日

这一页说说写的是妈妈时隔30年又参加村里社火表演，我想留住它是因为照片上那根花杆，妈妈真的把儿时的路又走了一次。

2014-2-14 23:18 发的说说（标题“从走一次儿时路”，部分好友可见）：“相隔30年，我又参加了村里的一次社火表演。还是在生我养我的小村庄，还是同一种节目。可我拿起那棍子，感到既熟悉，又陌生。30年过去了，我再也做不到儿时那轻巧的弹跳。即便是每天练到腰酸背痛，还是被教练拉出来当众出彩，我都是含泪忍着。因为我要坚持到最后，我要从走一次儿时路。30年，人这一生能有多少次，不是每个人都能像我一样，我不想错过我这人生路上的一道景。”浏览1次。“峰”评论：“老妈，我永远支持你！”
