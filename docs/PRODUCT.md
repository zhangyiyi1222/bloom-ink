# 产品说明

## 一、一句话

一个人像一朵花。面对世界时绽放，回到自己时入墨。

这个网站不证明一个人会多少东西，它只做两件事：

- **有时候我向世界打开** —— 绽放 · 本真 · 缘起。
- **有时候我把自己收回来** —— 归心（日志）。世界与我暂时没有关系，我爱写什么写什么。

不是两个网站，是同一个人的呼吸。

## 二、信息架构

```
首页  /                 你好，我是 … + 一排照片（七彩的世界）
├── 绽放  /bloom/       我与世界产生什么     淡紫
├── 本真  /self/        我是什么             淡粉
└── 缘起  /origin/      为什么               嫩绿

归心  /log/              与世界暂时无交集（墨色世界，导航里只剩这一个入口）
```

没有项目页、没有作品集、没有 About、没有说说、没有留言板、没有收藏、没有友链、没有能力页。
需要表达的东西全部变成文章。

**四个入口共用一套东西**：同一张 `articles` 表、同一个编辑器、同一个 Article Archive 组件、
同一个正文 renderer。区别只在氛围：

| 页面 | 底色 | 强调色 |
| --- | --- | --- |
| 首页 | 白底 + 七彩的 WebGL 花开 | 彩 |
| 绽放 | 白底 + 极淡紫环境光 | `#8a7ac8` |
| 本真 | 白底 + 极淡粉环境光 | `#cf7891` |
| 缘起 | 白底 + 极淡绿环境光 | `#6f9e5a` |
| 归心（日志） | 墨色纸面 `#f3f0e9` + 极淡水墨底 | `#5c564e` |

颜色只允许出现在标题下面那一条细线、链接 hover、极淡环境光上。正文永远是白底（或墨底）黑字。

## 三、顶栏

- 最左边是一个**小太阳图**（不是一个字）。点击回首页。太阳的光线里带一点七彩。
- 右边依次是：**首页 · 绽放 · 本真 · 缘起** · 搜索图标 · 世界图标。
- 在归心（墨色世界）里，导航**只剩一个「归心」**，搜索与世界图标不变。
- 顶栏是 sticky 的，底色比主页面浅一档并有极细的分隔线；向下滚动后加深并压出很轻的阴影，
  和下面内容形成层次。这一条参考了 project9 顶栏的做法。
- **左边界统一**：顶栏、页面标题、归档列表共用同一个 992px 容器，左边完全对齐。

## 四、URL 方案

| 页面 | URL |
| --- | --- |
| 首页 | `/` |
| 归档 | `/bloom/` `/self/` `/origin/` `/log/` |
| 文章 | `/bloom/<slug>/` … 稳定 permalink，不含任何查询参数 |
| 旧式日期链接 | `/bloom/2026/09/<slug>/` → 301 跳到上面的稳定地址 |
| 搜索 | `/search/`（任意页面按 `/` 也会打开同一个搜索） |
| 后台 | `/admin` |
| 订阅 | `/rss.xml`、`/log/rss.xml`、`/sitemap.xml` |

中文 slug 会写成百分号编码（`/log/%E5%9B%9E%E5%AE%B6/`），这样 sitemap、RSS、canonical 都是合规
URI，而浏览器地址栏和页面上仍然显示中文。

## 五、两个世界怎么切换

**绽放 → 入墨**：点右上角的小图标。墨点先落下，沿着噪声与纸纤维不规则扩散（有毛边、有停顿、
有分叉，前沿更湿更重），铺满整屏之后落到归心（日志）那一页。日志本身在墨色纸面上。

**入墨 → 绽放**：从归心点太阳。墨色里先长出一点嫩绿，再是粉、蓝、阳光黄，颜色从土地内部把墨
撕开、溶解，然后回到首页。

稳定之后动画基本停下，只剩纸纹、薄雾和非常缓慢的墨色呼吸。
「减少动画」的系统设置会自动降级成简洁的淡入淡出，世界照样能切换。

## 六、归档节奏

四个入口共用同一个 Article Archive 组件：**年 → 月 → 日期 + 标题自然流**。

- 每一个条目是 `日期 + 标题` 的完整 inline item；
- 同一行塞得下就继续放，塞不下整个 item 换行；
- 短标题可以让一行出现四五篇，长标题自然占更多空间；
- 间距关系永远是 **文章间距 < 月份间距 < 年份间距**；
- 日期浅灰、标题主色，没有 Badge、没有日历图标、没有胶囊。

## 七、文章页

骨架只有三样：标题、作者 / 日期、正文。没有 Hero 图、没有信息卡、没有阅读时长、没有 Tag 胶囊、
没有一排分享按钮。

正文 700px 宽、17px 字号、行高 1.9，中文思源宋体 / 西文 Palatino / 引用楷体 / 代码 Consolas。
正文结尾保持安静，只有 `← 上一篇` / `下一篇 →`。

### 正文支持的全部元素

| 元素 | 写法 | 说明 |
| --- | --- | --- |
| 标题 | `#` `##` `###` | 文章大标题已是 h1，正文里的 `#` 渲染成 h2 |
| 粗体 / 斜体 / 删除线 | `**粗**` `*斜*` `~~删~~` | 斜体用楷体 |
| 行内代码 | `` `code` `` | |
| 链接 | `[文字](地址)` | 外链有极轻的标记，不按钮化 |
| 引用 | `> 一句话` | 很细的左边线 + 轻微缩进，楷体 |
| 列表 | `-` / `1.` | |
| 代码块 | ` ```js ` | 语言标签、语法高亮、横向滚动、复制按钮 |
| 图片 | `![alt](地址 "caption")` | caption 写在 title 里；不写就不留位置 |
| 多图 | 连续 2–3 张图片各占一行 | 自动并排，不做瀑布流 |
| 视频 | 上传的 mp4/webm，或单独一行的 B 站 / YouTube 地址 | 自适应 16:9 |
| 音频 | `![录音](地址)` | 简单播放器 |
| 表格 | 标准 Markdown 表格 | 窄屏在容器内横向滚动 |
| 分割线 | `---` | 很轻 |
| 脚注 | `[^1]` + `[^1]: 内容` | Markdown 标准脚注 |
| 数学 | `$行内$` / `$$ 块级 $$` | KaTeX，只有用到公式的页面才加载它的样式 |
| 嵌入 | 单独一行的白名单地址 | 只允许 B 站 / YouTube / Vimeo |

**文章里的照片一律不超过正文文字的宽度。** `{.wide}` / `{.full}` 这两个写法仍然可以写（不会报错），
但不再把图片加宽；后台工具栏里也不提供这两个按钮。
Markdown 源里禁用了原始 HTML，所以不存在任意 HTML 注入面。

## 八、首页

和 zhangzhongwei.top 的首页一样：

1. 一颗太阳（和顶栏同一个图标，放大）；
2. `你好，我是 <名字>`；
3. 一句话；
4. 一排「晾在绳子上」的小照片 —— 取后台媒体库里最新的 12 张，轻轻摆动，点开看大图。

首页背后是七彩的花开（WebGL），颜色往四周散、中心留白，文字始终清楚。

## 九、后台

左导航只有四项：**概览 / 文章 / 媒体 / 视觉 / 设置**，顶部只有搜索和新建文章。

- **写作**：Markdown 是唯一真实格式，CodeMirror 提供语法高亮与快捷键；工具栏覆盖 H2/H3/H4、加粗、
  斜体、删除线、行内代码、引用、无序/有序列表、链接、图片、视频、音频、表格、分割线、脚注、公式、嵌入。
- **上传**：拖进编辑器、`Ctrl+V` 粘贴、或走媒体库选择，三条路都直接上传并插入 Markdown。
- **自动保存**：停手 1.4 秒后保存，状态一直显示 `保存中 / 已保存 / 保存失败`。
- **预览**：右侧就是真正的前台页面（同一个 renderer），可切桌面 / 手机。桌面预览用 1100px 视口
  渲染再缩放，看到的是真正的桌面排版。
- **版本历史**：每次实质修改留一个快照（最多 30 个），可从任意版本恢复。
- **回收站**：删除先进回收站，可恢复，也可以彻底删除。
- **媒体库**：上传后自动生成 WebP 优化版本与缩略图、读取尺寸、生成安全文件名；alt 与 caption 可编辑。
- **设置**：站点名称 / 名字 / handle / 域名 / 默认分享图 / 社交链接 / API 状态 / 数据导出 / 改密码。
- **视觉**：BLOOM 与 INK 各一份生成描述，一键生成候选，挑一张设为当前；历史图永远保留。

后台只回显「API 已配置 / 未配置」，永远不把 Secret 显示在网页里。

## 十、数据模型

```sql
articles            -- 一个模型装下四个入口
  id, title, slug, section(origin|self|bloom|log), content, content_format,
  status(draft|published|scheduled), published_at, permalink,
  seo_description, tags, word_count, created_at, updated_at, deleted_at
article_revisions   -- 版本历史（最多 30 版）
media               -- 媒体库（原图 / webp / 缩略图 / 尺寸 / alt / caption）→ 首页照片也来自这里
visual_assets       -- BLOOM / INK 基础视觉（prompt / provider / 历史 / 当前）
settings            -- 站点设置（key-value）
social_links        -- 社交链接（平台 / 显示名 / handle / 链接 / 是否显示 / 排序）
search_index        -- 搜索索引（标题 / 正文纯文本 / 日期 / 栏目 / slug / 标签）
sessions, users     -- 后台登录
```

## 十一、明确不做的

遇到拿不准要不要加的功能，默认不增加。当前明确允许的核心能力只有：
**文章、媒体、搜索、后台、两个世界的转换、极少社交链接**。

没有评论、没有访问统计、没有会员、没有邮件订阅、没有广告位、没有多作者、没有复杂分类树。

## 十二、修订记录

- 首页改成和 zhangzhongwei.top 一样的结构（太阳 / 你好，我是 … / 晾晒照片墙）。
- 顶栏：最左边由文字名改为小太阳图；顺序定为 首页 · 绽放 · 本真 · 缘起 · 搜索 · 世界图标；
  底色与主页面区分并有滚动层次；与页面标题、列表左边界对齐。
- 「本我」更名为「本真」。
- 墨色世界的入口定名为「归心」；页面标题仍是「日志」，副标题改成
  「世界先放一放，我回到自己这里。」
- 每个页面只属于一个世界（首页与三栏目 = 绽放，`/log/` = 入墨），切换世界是一次完整转场后跳转，
  不再在同一页里同时放两个世界。
- 文章里的照片一律不超过正文宽度。
- 字体与 zhangzhongwei.top / yihui.org 对齐（思源宋体 + Palatino + 楷体引用 + Consolas 代码）。
- 修掉三个真实缺陷：水墨底与全屏画布盖住正文（定位元素层级）、入墨时画布停止绘制（跳帧逻辑）、
  以及宋体在部分环境下把中文画成空白（字体栈）。
