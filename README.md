# 一个人像一朵花

> 面对世界时绽放，回到自己时入墨。

一套可以长期写下去的完整个人博客产品：前台是白底、大量留白、正文优先的中文阅读页，
后台是能真正拿来运营的写作工具。文章从头到尾都是 Markdown，随时可以整体带走。

```
首页        你好，我是 …           一个人站在门口
BLOOM 绽放  缘起 · 本真 · 绽放      与世界有交集的时候
INK  入墨   归心（日志）            与世界暂时无交集的时候
```

---

## 一、先用一句话说清楚它是什么

- **首页**像你现在的 zhangzhongwei.top 一样：一颗太阳、一句「你好，我是 …」、一排挂在绳上的小照片。
  照片直接来自后台的媒体库，删一张前台就少一张。
- **白底世界**有三个栏目：**绽放**（淡紫）· **本真**（淡粉）· **缘起**（嫩绿）。首页背景是七彩的。
- **墨色世界**只有一个入口：**归心**。点右上角那个小图标，墨会先在原地铺开，然后落到归心（日志）那一页。
  从归心点太阳，再回到绽放。
- **内容只有一种模型**：文章。四个入口用的是同一张表、同一个编辑器、同一个 renderer。
- **后台能做的事**：写、预览、上传图片/视频/音频、自动保存、版本历史、回收站、发布、搜索、换基础视觉。

## 二、怎么把它跑起来

需要先装好 **Node.js 22.5 或更新的版本**（[nodejs.org](https://nodejs.org) 下载 LTS 即可）。

```bash
npm install        # 安装依赖（会联网下载，几分钟）
npm run build      # 打包前台与后台的前端代码
npm run reset      # 生成一份干净的演示数据（114 篇文章 + 首页照片 + 基础视觉）
npm start          # 启动
```

启动后：

- 前台：<http://127.0.0.1:8787/>
- 后台：<http://127.0.0.1:8787/admin>

**第一次打开后台**会让你设置管理员密码（用户名默认 `admin`）。

> 风险提示：`npm run reset` 会清空文章、媒体、视觉素材和后台账号，重新生成演示数据。
> 只在刚上手、准备换成自己内容之前用一次。想保留后台账号就加 `-- --keep-admin`。

## 三、日常怎么用

| 我想做的事 | 怎么做 |
| --- | --- |
| 写一篇文章 | 后台 → 新建文章 → 选栏目 → 写 → 发布 |
| 换首页照片 | 后台 → 媒体 → 上传（首页自动取最新的 12 张） |
| 插一张照片 | 工具栏「图片」选图，或直接把图拖进编辑器 / `Ctrl+V` 粘贴 |
| 插视频 | 工具栏「视频」选本地文件；或把 B 站 / YouTube 地址单独放一行 |
| 插一段录音 | 工具栏「音频」选文件 |
| 先不发布 | 状态保持「草稿」，或选「定时发布」 |
| 看看发布后的样子 | 编辑器右侧就是真实前台页面（桌面 / 手机两种宽度） |
| 改错了想退回去 | 编辑器顶部「版本」，选一个历史版本恢复 |
| 误删了文章 | 后台 → 文章 → 回收站 → 恢复 |
| 换首页的花 / 墨 | 后台 → 视觉 → 写描述 → 生成 → 设为当前 |
| 换社交链接 | 后台 → 设置 → 社交（最多 4 个，前台只显示小图标） |
| 把内容带走 | 后台 → 设置 → 数据：导出 Markdown 或下载完整备份 |

### 前台快捷键

| 键 | 作用 |
| --- | --- |
| `/` 或 `Ctrl/Cmd + K` | 打开搜索 |
| `Esc` | 关闭搜索 |
| `←` / `→`（文章页） | 上一篇 / 下一篇（输入框里不会触发） |

搜索语法：`AI 短剧` 同时包含 · `AI | 短剧` 任一 · `"一人公司"` 精确短语。

## 四、字体与排版

和 zhangzhongwei.top、yihui.org 同一套：

- **中文正文**：思源宋体（本机装了就用本机的，否则用项目自带的那份子集，已 preload）
- **西文**：Palatino
- **引用 / 斜体**：楷体
- **代码**：Consolas
- 正文 700px 宽、17px 字号、行高 1.9；页面统一 992px 容器，顶栏、标题、列表左边界完全对齐

> 小提示：字体列表里**故意不写** `SimSun`（宋体）。宋体在部分渲染环境下会把中文画成空白，
> 而且它的字形也不是参考站用的那一套。

## 五、目录里有什么

```
src/server/          服务端：路由、数据、Markdown 渲染、图像生成
  routes/public.mjs  前台路由（首页 / 归档 / 文章 / 搜索 / RSS / sitemap）
  routes/admin.mjs   后台 API 与后台页面外壳
  markdown.mjs       正文 renderer（后台预览与前台共用同一份）
  articles.mjs       文章模型、版本历史、回收站、归档树
  media.mjs          媒体库（上传、WebP 优化、缩略图、尺寸）
  visuals.mjs        BLOOM / INK 基础视觉（本地程序化 + 豆包 provider）
  seed.mjs           演示数据（含一篇把所有组件都用上的测试文章）
src/views/           前台模板（EJS，服务端渲染，对 SEO 友好）
web/site/            前台前端：WebGL 世界、入墨转场、搜索
web/admin/           后台前端（React + CodeMirror 6）
public/static/fonts/ 思源宋体 + 楷体子集
public/static/home/  首页照片样片（npm run reset 时会装进媒体库）
scripts/             构建辅助与自检脚本
data/                你的数据（数据库、上传文件、视觉素材、备份）
```

## 六、自检

```bash
npm run check      # 全部：渲染器 + SEO/可见性 + 前台 + 后台（用真 Chrome 跑，含像素级校验）
```

它会检查 90 项：WebGL 有没有真的画出世界、文字有没有真的画在屏幕上、
顶栏与列表是否对齐、世界切换后落到哪一页、正文组件齐不齐、阅读宽度与字号、
搜索三种语法、后台能不能真发布、移动端有没有横向滚动、SEO 与 RSS 是否合规。
截图留在 `shots/`。

单独跑：`npm run check:md` · `npm run check:site` · `npm run check:admin` · `npm run check:misc`

## 七、备份与迁移

```bash
npm run backup    # 完整备份 → data/backups/bloom-ink-<时间>.zip
npm run export    # 只导出文章 → data/markdown-export-<日期>.zip
npm run admin:password   # 重设后台密码
```

- **迁移 / 上线**：把整个 `data/` 目录拷走即可。
- **换博客系统**：`npm run export` 出来的 `articles/` 是纯 Markdown，任何静态博客都能直接用。
